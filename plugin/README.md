# Hermes Jr. Companion

The Hermes plugin for the Hermes Jr. iPhone app.

Before installing or pairing, read the bundled [INSTALL.md](INSTALL.md) and follow its required fresh-install check and user-facing handoff. Hermes runs setup and waits for the phone; the user scans the private browser QR and connects automatically. No fingerprint exchange or second approval.

For setup, updates, and help, read the [main guide](https://github.com/cyberculturedhq/hermes-jr-companion).
