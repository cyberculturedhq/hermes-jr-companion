# Hermes Jr. Companion

The Hermes plugin for the Hermes Jr. iPhone app.

To install and connect an iPhone, follow [INSTALL.md](INSTALL.md) with the setup ticket copied from Jr.

For setup, updates, and help, read the [main guide](https://github.com/cyberculturedhq/hermes-jr-companion).
