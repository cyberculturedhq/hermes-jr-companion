# Hermes Jr. Companion

The Hermes plugin for the Hermes Jr. iPhone app.

Before installing or pairing, read the bundled [INSTALL.md](INSTALL.md) and follow its required fresh-install check and user-facing handoff. With a phone-bound setup ticket, Hermes waits while the user compares the code on both devices and taps “Codes match — Connect” on the iPhone. Private browser QR pairing remains available as an explicit fallback.

For setup, updates, and help, read the [main guide](https://github.com/cyberculturedhq/hermes-jr-companion).
